# 🌌 2D Solar System Simulation

A simple 2D Solar System simulation built with **Python** and **Pygame**.

This project was created as my first personal Python project after completing a Python course. The goal was to practice programming fundamentals while building something visual and interactive.

## ✨ Features

* ☀️ Sun and planets displayed in a 2D environment
* 🪐 Planets orbit around the Sun
* 🏷️ Planet labels for easier identification
* 🎨 Simple visual representation of the Solar System
* 🖥️ Interactive Pygame window
* ⚙️ Built entirely with Python and Pygame

## 🛠️ Technologies Used

* **Python**
* **Pygame**

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

### 2. Navigate to the project folder

```bash
cd YOUR_REPOSITORY
```

### 3. Install Pygame

```bash
pip install pygame
```

### 4. Run the simulation

```bash
python main.py
```
